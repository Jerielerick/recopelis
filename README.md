# Recopelis

Plataforma IPTV/VOD multiplataforma orientada a la gestión y reproducción de contenido mediante listas M3U, Xtream Codes y streaming HLS.

## Tecnologías principales

- React
- TypeScript
- Vite
- Firebase
- HLS.js
- React Router
- ESLint

## Funcionalidades y enfoque

- Soporte para fuentes IPTV/VOD.
- Integración con listas M3U.
- Compatibilidad con Xtream Codes.
- Reproducción de contenido HLS.
- Navegación mediante React Router.
- Integración con Firebase.
- Interfaz web desarrollada con React y TypeScript.

## Estructura del proyecto

```text
recopelis/
├── web/                         # Aplicación web principal
├── docs/                        # Documentación
├── INSTRUCCIONES_EJECUCION.md   # Guía de ejecución
├── ROADMAP.md                   # Planeación del proyecto
└── CHANGELOG.md                 # Registro de cambios
```

## Ejecución local

La aplicación web se encuentra en la carpeta `web`.

```bash
cd web
npm install
npm run dev
```

Para generar una versión de producción:

```bash
npm run build
```

## Objetivo del proyecto

Este proyecto permite practicar desarrollo frontend moderno con React y TypeScript, integración de servicios externos, reproducción multimedia en web y organización de una aplicación multiplataforma.
